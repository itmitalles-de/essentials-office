# Onboarding checklist (synthetic template)

Use only with the fictional HR Lite demonstration accounts. Assign exactly one
responsible person and track the work in the HR Lite Deck board.

- [ ] Employee directory account created and assigned to `employee`
- [ ] Manager assigned and welcome information shared
- [ ] Onboarding Form submitted
- [ ] Required access approved by `hr-admin`
- [ ] Confidential documents stored in **HR Lite - Confidential**
- [ ] First-day and 30-day check-ins scheduled in Calendar

Status: `new` → `in progress` → `ready` → `completed`
