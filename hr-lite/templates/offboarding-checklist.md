# Offboarding checklist (synthetic template)

Use only for the fictional demonstration workflow. Do not enter real employee
or employment data in this repository.

- [ ] Responsible `hr-admin` assigned
- [ ] Departure date confirmed in the HR Lite Table
- [ ] Manager review completed
- [ ] Access-removal tasks created in Deck
- [ ] Confidential documents retained or removed according to the separately
  approved retention policy
- [ ] Calendar appointments and open absence requests reviewed

Status: `requested` → `review` → `access removal` → `closed`
