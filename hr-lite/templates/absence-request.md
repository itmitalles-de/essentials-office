# Absence request (synthetic template)

Employees submit this information through the **HR Lite – Absence request**
Form; HR does not use this Markdown file as a data store.

| Field | Value type |
| --- | --- |
| Request reference | Synthetic identifier |
| Requester | Nextcloud account |
| Start and end | Calendar dates |
| Reason category | Leave / illness / other |
| Status | submitted / manager review / approved / rejected / cancelled |
| Responsible | `manager` or `hr-admin` |

Only `hr-admin` maintains the HR Lite Table containing request status. Managers
receive only the individual request necessary for their review; employees do
not receive the confidential HR document area.
